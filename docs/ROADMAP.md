# Outstanding activities

What is left, in the order it should be picked up. Every item names the
workstream milestone that owns it, so this file stays a view rather than a
second source of truth — the milestone tables in `docs/workstreams/` are
authoritative, and `orgagents records validate` keeps them honest.

Generated by hand on 2026-09-20, after WS-025 M4 (runtime mission expiry)
landed. Records: 41 ADRs, 27 workstreams, 0 violations. Tests: 333 passing.

## Where the system stands

Shipped and exercised by tests: the spec language and validator, the
implementation-neutral IR, all four compile targets (local Docker, Terraform
for GCP/AWS/Azure), the runtime as a target consumer, RBAC with least-privilege
checks, sandbox environment classes and per-agent narrowing, two-tier memory,
sub-agents as tools, guardrails, context and output contracts, scheduling and
triggers, human channels and approval routing, the designer backend with
RBAC/locks/merge, the drag-and-drop canvas, missions, model governance and the
platform catalog.

The gaps below are real, and the README's "Known limits" section states them in
user-facing terms. Nothing here is a surprise discovered late; each was
recorded as a milestone when the feature it belongs to landed.
