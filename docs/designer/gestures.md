## Removing

| Gesture | Operation | Accepted | Refused |
|---|---|---|---|
| select an edge that is not a composition and press Delete | `unlink «<edge's relationship>»` | the edge disappears; both boxes remain | a composition edge cannot be removed alone — the part would have no whole; the status line says to move it or delete it |
| select a box and press Delete | `delete` | the box, its parts and every link to it disappear; the status line lists each link destroyed, and Undo restores them all | nothing is removed; the status line names what still requires it (a trigger that must fire it, a step that calls it) |
